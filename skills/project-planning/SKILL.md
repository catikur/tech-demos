# Project planning

Before coding a demo under `apps/<slug>/`:

1. Name a kebab-case `slug` and target path `apps/<slug>/`.
2. Write `apps/<slug>/PLAN.md` with:
   - Goal (one paragraph)
   - Source bookmark / upstream repo
   - MVP scope (in / out)
   - Stack (Bun-first)
   - UX sketch (screens)
   - Success criteria including screenshot + video artifacts for the PR
3. Keep the plan short enough to implement in one cloud-agent PR.
4. Do not expand into other apps/ or invent a new repo.
